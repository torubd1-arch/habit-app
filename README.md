# 習慣メモ（自分専用の習慣記録アプリ Ver.1）

iPhone で「起動 → 1回タップ → 終了」で記録するための静的Webアプリです。
ストレッチ・パター練習・禁酒・アプリ開発・筋トレ・エアロバイク・水（500ml×4回）・24時までに寝た、の8項目を記録し、月間カレンダーで振り返ります。

- 記録はブラウザ内（localStorage `personal-habits-v1:data`）にだけ保存され、サーバーへは送りません。
- 登録・ログイン・同期・通知・アクセス解析・外部CDNはありません。

## フォルダ構成

```text
index.html / manifest.webmanifest / sw.js / .nojekyll
css/styles.css
js/app.js          初期化、タブ、復帰、イベント
js/habits.js       項目定義
js/dates.js        日付の純粋関数
js/model.js        デフォルト、導出、検証
js/storage.js      保存、競合、エラー
js/backup.js       書き出し、検証、復元
js/calendar.js     月間生成とフィルター
js/record-view.js  今日・日別編集の共通UI
icons/             アイコン（tools/make-icons.mjs で生成）
tests/             自動テスト（node:test）
tools/             開発用（アイコン生成、ローカルサーバー）。公開されても動作に影響しません
```

## ローカルで起動する

ES Modules と Service Worker を使うため、`file://` で直接開くことはできません。HTTP サーバー経由で開いてください（Node.js 18 以上）。

```sh
cd habit-app
npm run serve        # = node tools/serve.mjs 8080
# ブラウザで http://localhost:8080/ を開く
```

## テスト

```sh
npm test             # = node --test "tests/*.test.js"
```

日付（JST・夏時間・うるう年）、水の16通り、睡眠の保存先、保存失敗、データ破損、競合、バックアップ検証・置換・読み込み前に戻す、を確認します。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリ（例：`habits`）を作成します。
2. このフォルダ（`habit-app` の中身）をリポジトリのルートに置いて push します。
   ```sh
   cd habit-app
   git init
   git add .
   git commit -m "習慣メモ Ver.1"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
3. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存します。
4. 数分後に `https://<user>.github.io/<repo>/` で開けます。アドレスが **https** になっていること（鍵マーク）を確認してください。

すべて相対パスなので、リポジトリ配下でもドメイン直下でも動作します。
バックアップファイル（`habits-backup-*.json` など）は `.gitignore` で除外しています。実データをリポジトリに入れないでください。

> 同じ `<user>.github.io` の他のアプリは同じ保存領域（origin）を共有します。信頼できないコードと同じ origin に置かないでください。

## iPhone で使い始める

1. Safari で公開URLを開きます。
2. 共有ボタン →「ホーム画面に追加」。
3. **ホーム画面のアイコンから起動して**、日々の記録を始めます。
   - Safari とホーム画面版は記録が別々に保存されます。どちらか一方（ホーム画面版）を使ってください。
   - 同じアプリを複数タブで同時に編集せず、普段はホーム画面版を1つ使ってください。

### オフラインの準備

オンラインで一度起動し、設定画面に「オフラインでも使えます。」と表示されれば準備完了です。以降は機内モードでも起動・記録・カレンダー閲覧ができます。初回をオンラインで開く前はオフラインでは起動できません。

### 更新

新しい版を公開するときは `sw.js` の `CACHE_NAME`（`personal-habits-shell-v1`）の番号を上げてください。使用中のアプリが突然リロードされることはなく、アプリを閉じて開き直した後に新しい版になります。記録は消えません。

## 使い方

- **今日**：行をタップで記録、もう一度タップで取消。保存ボタンはありません。
  - 「昨夜24時までに寝た」は**前日**の記録になります（記録先の日付が表示されます）。
- **カレンダー**：全体（✓達成数/7・水の回数）または習慣ごとに表示。日付をタップすると下にその日の記録が開き、修正できます。日別編集の睡眠は「その日の夜」です。未来の日は編集できません。
- **設定**：バックアップの書き出し・読み込み。

## バックアップ（大切）

記録は端末のブラウザ内にだけあります。機種変更、ブラウザデータの削除、OS のストレージ整理などで消える可能性があるので、定期的に書き出してください。ホーム画面に追加しただけでは消失対策にはなりません。

- **書き出し**：設定 →「バックアップを書き出す」→ 共有シートで「"ファイル"に保存」を選びます（共有に対応しない環境ではダウンロード）。保存できたかは「ファイル」アプリで確認してください。
- **読み込み**：設定 →「バックアップを読み込む」→ ファイルを選択 → 内容（日数・期間・書き出し時刻）を確認 →「現在の記録を置き換える」。マージはせず、全体を置き換えます。
- **読み込み前に戻す**：直前の読み込みを1回だけ取り消せます。
- **Safari からホーム画面版へ移行**：Safari で書き出し → ホーム画面版で読み込み。
- 保存データが壊れて読めない場合は入力が停止します。設定の「保存データをそのまま書き出す」（.txt）で退避してから、正常なバックアップを読み込んで復旧してください。
